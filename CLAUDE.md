# friendly-friend

Conventions and design decisions live in `.ai/rules/` (start with `general.md`; `index.md` maps paths to rule files). Keep them current in the same commit as the change.
Process rules are generated by Laravel Boost into AGENTS.md from `.ai/guidelines/workflow.md` plus the package guidelines. Edit those sources, then run `vendor/bin/sail artisan boost:update`. Never edit AGENTS.md by hand.
