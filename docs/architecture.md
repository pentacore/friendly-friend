# Architecture

Full design: [`docs/superpowers/specs/2026-11-26-friendly-friend-design.md`](superpowers/specs/2026-11-26-friendly-friend-design.md).

```
Discord gateway ──► bot (php artisan bot:run, DiscordPHP)
                       │  turns each event into a small data object and queues a job; no business logic
                       ▼
                  Redis ◄──► Horizon workers ──► PostgreSQL
                                   │──► AI provider (laravel/ai)  [Phase 4]
                                   └──► Discord REST
Browser (Vue/Inertia) ──► web ──► PostgreSQL / Redis
                       ◄── Reverb (WebSockets, Echo)
```

## Services

| Service               | Dev (Sail, `compose.yaml`)                         | Prod (`compose.prod.yaml`) | Command                                   |
| --------------------- | -------------------------------------------------- | -------------------------- | ----------------------------------------- |
| Web                   | `laravel.test`                                     | `web` (FrankenPHP)         | built-in server / `frankenphp php-server` |
| Queue workers         | `horizon`                                          | `horizon`                  | `php artisan horizon`                     |
| WebSockets            | `reverb` (port 8080)                               | `reverb`                   | `php artisan reverb:start`                |
| Scheduler             | n/a (run `sail artisan schedule:work` when needed) | `scheduler`                | `php artisan schedule:work`               |
| Discord bot           | `bot` (profile `bot`, see [bot.md](bot.md))        | `bot`                      | `php artisan bot:run`                     |
| Database              | `pgsql` (Postgres 18)                              | `postgres`                 |                                           |
| Cache, queue, session | `redis`                                            | `redis`                    |                                           |
| Mail catcher          | `mailpit` (UI on :8025)                            | n/a                        |                                           |

## Dashboards

- **Horizon** `/horizon`: always open in `local`. Elsewhere the `viewHorizon` gate (`app/Providers/HorizonServiceProvider.php`) denies everyone until Phase 2, which limits it to Discord admins.
- **Telescope** `/telescope`: only registered in the `local` environment (`AppServiceProvider::register()`). It's a dev dependency and never installed in production.

## Realtime

Broadcasting uses Reverb. The frontend sets up Echo in `resources/js/app.ts` (`configureEcho({ broadcaster: 'reverb' })`). Channel authorization lives in `routes/channels.php`. Broadcast event payload types are generated by Typefinder into `resources/js/typefinder/broadcasting.d.ts`.

## Access

Discord OAuth only (Socialite). Guild membership and roles are enforced on every request. See [auth.md](auth.md).
