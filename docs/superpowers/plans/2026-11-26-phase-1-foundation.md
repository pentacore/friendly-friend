# Phase 1: Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running Laravel 13 Vue starter-kit app on Sail (PHP 8.5, Postgres, Redis), with the full quality toolchain, Typefinder, Horizon, Reverb and Telescope installed, plus Boost rules, docs, CI and a production Docker image. Every check passes.

**Architecture:** Scaffold the official `laravel/vue-starter-kit` into a temp directory and move it into this repo, which already holds `docs/`. All PHP commands run through Sail (`vendor/bin/sail …`), because the host only has PHP 8.3. Production uses one FrankenPHP PHP 8.5 image with a separate command per service.

**Tech Stack:** Laravel 13, Inertia 3 + Vue 3 + TS (vite-plus), Fortify, Wayfinder, pentacore/laravel-typefinder, Pest 5, Larastan, Rector, Pint, Horizon, Reverb, Telescope, Laravel Boost, Sail, FrankenPHP.

**Spec:** `docs/superpowers/specs/2026-11-26-friendly-friend-design.md`

## Global Constraints

- `composer.json` `"php": "^8.5"`. Sail runtime `8.5`. Production image `dunglas/frankenphp:1-php8.5`.
- Database is PostgreSQL (`DB_CONNECTION=pgsql`). Queue, cache and session use Redis.
- Typefinder: `gitignore_generated => false`, output committed to `resources/js/typefinder/`. Inertia and broadcasting categories enabled. CI runs `typefinder:generate --check --strict`.
- Larastan level `max`.
- **Every commit updates the affected `.ai/guidelines/*` and `docs/*` in the same commit** and runs `sail artisan boost:update` when guidelines change.
- Line endings LF (`.gitattributes` `* text=auto eol=lf`).
- Commit messages: conventional commits, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Alias used below: `sail` = `vendor/bin/sail`.

- [ ] **Step 1: Write `scripts/check-docs-updated.sh`** (warns, never fails):

```bash
#!/usr/bin/env bash
# Warn when app code/schema/routes change without any docs or AI-guideline change.
set -euo pipefail
base="${1:-origin/main}"
changed=$(git diff --name-only "$base"...HEAD)
if echo "$changed" | grep -qE '^(app|database|routes|config)/' && ! echo "$changed" | grep -qE '^(docs|\.ai)/'; then
  echo "::warning::Code changed without updates to docs/ or .ai/guidelines/. Update rules & docs in the same change."
fi
```

### Task 8: Production image and compose

**Files:**
- Create: `Dockerfile`, `compose.prod.yaml`, `.dockerignore`, `docker/entrypoint.sh`, `docs/deployment.md`

- [ ] **Step 1: Write `Dockerfile`** (multi-stage):

```dockerfile
FROM dunglas/frankenphp:1-php8.5 AS base
RUN install-php-extensions pdo_pgsql pgsql redis pcntl intl zip bcmath opcache
WORKDIR /app

FROM base AS vendor
COPY --from=composer:2 /usr/bin/composer /usr/bin/composer
COPY composer.json composer.lock ./
RUN composer install --no-dev --no-scripts --no-autoloader --prefer-dist
COPY . .
RUN composer dump-autoload --optimize --no-dev

FROM node:24-alpine AS assets
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
COPY --from=vendor /app/vendor ./vendor
RUN npm run build

FROM base AS app
ENV APP_ENV=production SERVER_NAME=:80
COPY --from=vendor /app /app
COPY --from=assets /app/public/build /app/public/build
COPY docker/entrypoint.sh /usr/local/bin/entrypoint
RUN chown -R www-data:www-data storage bootstrap/cache && chmod +x /usr/local/bin/entrypoint
USER www-data
ENTRYPOINT ["entrypoint"]
CMD ["frankenphp", "php-server", "--root", "/app/public"]
```

If `npm run build` needs PHP (the Wayfinder or Typefinder Vite plugins generate at build time), build the assets in a stage `FROM base` with Node installed instead, and set the Typefinder plugin's `buildCommand: false` since its output is committed.
